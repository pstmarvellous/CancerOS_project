# Data and AI safety implementation rules

COS-005. Source: SPEC-010 SAFE-01–25, SPEC-008 sections4/17/19, audit A02/A06/D01–05.
Machine-readable invariants retain all 25 SAFE IDs; engineering-only negative scenarios
are in fixtures/engineering/safety-cases.json. They are planned test designs, not runtime passes.

Canonical origins: REAL_OBSERVED, REAL_DERIVED, SYNTHETIC_GENERATED, INTERPOLATED,
MODEL_PREDICTED. Processing synthetic content keeps synthetic origin. Availability,
technical QC, clinical validity and publication are independent. Only explicit shared
baseline links cross observed/branch context. Source corrections/retractions append;
snapshots retain exact prior membership. Enforce ownership in API and database.

Preserve time domains, units, original values and censored comparator/thresholds.
Unknown never becomes zero, negative receptor status or an invented date. DCE phases
remain within examinations. Bounding boxes, functional masks and anatomical contours
support different claims. Volume is not diameter or RECIST; incompatible comparisons abstain.

External inference is denied by default. A versioned allowlisted minimized payload
requires permission evidence; no default raw DICOM, protected mappings, unrestricted
notes or secrets. Notes, retrieved content and model prose cannot grant privileges.
Numeric findings come from deterministic records; schema/citation existence does not
prove truth. Failed grounding must block the entire unsupported publication.

No invented stage, pathology, HER2, causal efficacy/toxicity, survival, resistance,
patient-specific prescribing or treatment ranking. No simulated outcome as authentic.
Geometric perturbations are not prediction intervals; QC is not clinical approval.
Forecasting and automatic CTCAE/RECIST grading stay disabled pending reviewed gates.

Each invariant has planned enforcement/test/failure/fallback fields. Full runtime
enforcement is future work, not implied by this document. D01–D05 remain open.
No clinical reference interval, conversion dictionary or medical policy is invented.
Academic/clinical standards were retrieved as pointers only for this governance task;
actual clinical rule implementation must inspect applicable source text separately.
