# ADR-023: authenticated engineering mesh preview

COS-036, 2026-10-28. SPEC-005 §9.5, SPEC-009 §7/14, SPEC-010 §7 and Phase1 frontend
security govern this bounded preview. It is reusable engineering visualization,
not the full future case/timeline workspace, anatomical review or public demo.

Use existing canonical authenticated QC-report, selected-asset and measurement reads.
No new backend transport or public object access. Token is kept in React memory,
never URL/storage/logs; the API origin is configured at build time, not editable in
the user flow. New selections clear old geometry immediately and abort old requests.
The source-mask measurement remains authoritative, with annotation UUID/class,
synthetic origin, RAS/mm and available source-time basis visible. A numeric/functional
region is not renamed as approved anatomical tumor. Private source times are not
fabricated from revision numbers or UI load time.

Use pinned Three0.186.1 (MIT), generated API TypeScript and demand rendering. World
coordinates are retained; orthographic camera changes view only. Select annotations
without per-object normalization. Keyboard/buttons supplement pointer controls;
interaction requires an explicit action so canvas gestures do not consume page
scrolling. Reset/fit camera does not change scientific values. Dispose resources
on replacement/unmount; WebGL failure retains text measurements and retry guidance.

No eligible patient breast-region context exists. Omit it with an explicit message;
do not create a shell implying source anatomy, a nonworking context toggle, right/
left claim or patient-specific distance/invasion/surgical conclusion. Public-demo
rights and source/qualified scientific reviews remain unestablished.

The mandatory local browser smoke uses a separate temporary API, ephemeral RS256
identity, disposable SQL and private S3 synthetic pipeline. It cannot overwrite an
existing API/configuration. Its ignored private bundle is not evidence and must be
removed when the owned server is stopped. Screenshots must omit credentials.
Task-specific component/browser/evidence checks determine current results; no
target-device/browser performance threshold is claimed without its required trials.
