# ADR-002: later viewer integration options

COS-011; status: reference comparison, no viewer selected or integrated in Phase1.
Map references: REF.OHIF/UX.TIMELINE and academic UX.01/TWIN.02 in COS-011 context.
Candidate OHIF embedded workspace offers existing imaging navigation/measurement
tracking but needs patient/branch synchronization and potentially heavier deployment.
Candidate Cornerstone3D in a custom Next.js workspace offers tighter shell/timeline
control but requires more viewer/annotation engineering. Compare MRI loading, mask
alignment, state switching, bundle/memory and public APIs in a later bounded experiment.
No upstream version/commit/source was inspected or reproduced for this shell task;
this is a map-derived comparison, not verified compatibility or an adoption decision.
