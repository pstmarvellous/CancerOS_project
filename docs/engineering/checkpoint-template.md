# Task checkpoint

Task/status; exact completed unit; touched files; requirement/map IDs; spec sections
actually read; commands/results and safe artifact paths; decisions; gaps/blockers;
next bounded action and minimal resume instruction. Never include secrets, raw notes,
copyrighted chapters or hidden reasoning. Record completion time only when complete.

Resume example: COS-010 interrupted after contract tests. Read root AGENTS, ledger
and COS-010 reference record; requery both maps for time/provenance; inspect SPEC-008
sections4/13; preserve changes; run the recorded failing contract test; fix only the
identified serializer; rerun affected checks; update evidence. Do not claim it passed
because the checkpoint names a test.
