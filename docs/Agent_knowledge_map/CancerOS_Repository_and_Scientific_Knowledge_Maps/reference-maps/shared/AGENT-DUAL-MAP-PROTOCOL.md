# AGENT DUAL-REFERENCE PROTOCOL — COS-REF-MAPS-003

## Entry condition (every substantial task)
1. Read root `AGENTS.md`, both maps, and authoritative relevant CancerOS specification(s).
2. Query the same behavior ID in `repository-map/behavior-to-repository.json` and `scientific-map/behavior-to-evidence.json`.
3. Read actual academic/lecture sections. Log title, section/chapter, URL, edition/version and observed claim; do **not** invent pages.
4. Inspect relevant upstream source files/docs, selected commit, license, model/data licensing, APIs, test coverage and compatibility; if unavailable, label `not_verified`.
5. For evidence-sensitive scientific behavior consult relevant paper(s) and check the original publication, cohort, metric and limitations.
6. Produce **Source Learning Record**: behavior ID, task, research question, source locators, what each supports, unsupported assumptions, conflicting evidence, access limitations.
7. Produce **Engineering Decision Record**: adopt dependency / adapt with attribution / study and implement / defer; contracts, licensing, prerequisites, alternate implementation and decision rationale.
8. Execute a small deterministic test or bounded reproducibility test. Record environment, upstream commit, command, output, errors, hashes, resource use where applicable.
9. Implement behind CancerOS-owned typed interfaces; preserve provenance, patient/branch isolation, spatial geometry and clinical safeguards.
10. Run task-specific regression/negative tests, update traceability and ledger, and declare what was actually verified.

## Escalation rules
- No automatic copying of unknown-license code or model checkpoints.
- Do not count multiple DCE acquisitions as longitudinal visits.
- Do not equate reference masks, functional volume masks, bounding boxes or generated meshes.
- Do not infer patient treatment effect from synthetic branches.
- Do not invent real data, clinical ranges, research citations, human review or passing tests.
- Source code, scientific paper, and textbook may disagree; record the conflict and defer an unsafe decision while continuing independent tasks.
- For routine UI/plumbing tasks, a brief dual-map lookup and scoped no-match record is sufficient: do not force unrelated textbook research.
- The twelve specifications own project intent; maps are navigation indexes and never override user instructions or source licenses.
